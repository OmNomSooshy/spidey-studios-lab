Little Bob

His existing house, backyard and Crystal world, bundled inside a standalone Android app. No game server or account needed after installation.

Download Little Bob APK

Version 1.0.0 · about 2 MB · Android 8 or newer with a recent Android System WebView / Chrome.

Package: com.spideystudios.littlebob

Install

  1. Download the APK. If using Management's phone, send this file to Lilli's phone.
  2. Open the downloaded APK. Android may ask you to allow installation from the browser or Files app you used. Allow that source for this installation.
  3. Tap Install, then Open. The installed app is named Little Bob.
  4. After installation, you can turn off “Allow from this source” again. No overlay, root or developer mode is required.

Keep the app installed for future updates. Uninstalling deletes its local saved progress.

His senses

Camera and microphone are optional. Android asks only when you open his sensory window. Motion sensors need no permission dialog. Vibration and the normal WebView internet permission are declared; gameplay assets are local, and the wrapper blocks remote content.

No notification, location, contacts, broad storage or draw-over-other-apps permission.

Already have a browser home?

Chrome and an Android app have separate private storage. The rename keeps the existing save keys, but Android cannot silently read Chrome's saved home.

  1. On the same browser/profile where you played, download your saved home.
  2. Transfer that JSON file to the installation phone if necessary.
  3. Long-press the installed Little Bob launcher icon and choose Bring browser save.
  4. Select the JSON, confirm the import, and reopen his home. The browser's original save remains untouched.
